# Post Management Implementation Plan

## Overview

Implement a complete post management feature (`feature/post/`) mirroring the established hexagonal architecture of `feature/user/`. The feature supports post CRUD, media upload with transaction rollback cleanup, soft-delete, feed pagination, and cross-feature integration via `UserQueryPort` and `MediaStoragePort`.

## Requirements

- Create and read posts with denormalized author snapshot (`authorName` = `externalId`)
- Upload and manage post media (images/video) with separate endpoints
- Update post content and delete individual media items
- Soft-delete posts with repository-level filtering
- Paginated feed endpoint `GET /api/v1/users/{userId}/posts`
- Transaction rollback cleanup for media uploads
- Media validation: max 10 files per post, max 10MB per file, images/video only
- Full test coverage following the 5-layer test matrix

## Current State Analysis

The `feature/user/` package provides the architectural template:
- `UserService.java:36` — package-private `@Service` implementing multiple ports
- `UserController.java:22-31` — `@RestController` wired only to ports with `resolveUserId(Principal)`
- `MediaStoragePort.java:13-39` — cross-feature port for file storage
- `LocalMediaStorageAdapter.java:23-93` — local filesystem adapter with path validation
- `UserMapper.java:14-28` — MapStruct Spring-component mapper with multi-source mappings
- `GlobalExceptionHandler.java` — catches `NotFoundException` → 404, `AccessDeniedException` → 403, `ValidationException` → 400

No `feature/post/` package exists yet. All post-related code must be created from scratch following the user feature patterns.

### Key Discoveries

- `UserService.java:51` injects unqualified `MediaStoragePort`; adding a second adapter requires `@Qualifier` here
- `UserService.java:112-119` — upload flow with `registerRollbackCleanup(url)`
- `UserService.java:169-180` — `TransactionSynchronizationManager.registerSynchronization` for rollback cleanup
- `LocalMediaStorageAdapter.java:60` — binary `avatars`/`tracks` branch in `delete()`; needs extension for `/post-media/`
- `SecurityConfig.java` — currently no explicit `/api/v1/posts/**` rule; falls under `.anyRequest().authenticated()`
- `application.yaml:10` — `ddl-auto: validate` requires exact Flyway-to-JPA alignment
- `ddl-auto: validate` + Flyway means zero tolerance for schema drift

## What We're NOT Doing

- **Comments**: Out of scope; may need `PostContextPort` in future
- **Real-time updates**: No WebSocket/SSE feed
- **Caching layer**: No Redis/caffeine for feeds
- **authorAvatarUrl**: Explicitly excluded from all contracts per developer decision
- **Media reordering**: `sortOrder` is set at insertion time; no explicit reorder endpoint
- **Hard delete**: Only soft-delete is implemented; physical deletion of media on soft-delete is deferred
- **Public/anonymous feeds**: All endpoints require authentication

## Decisions

### Post Creation Media API: Separate Endpoints

**Explored:**
- Option A — Inline only: `POST /api/v1/posts` accepts content + files in one multipart request. Simplest but doesn't match research's "standalone media upload" requirement.
- Option B — Separate endpoints: `POST /api/v1/posts` (content only), then `POST /api/v1/posts/{postId}/media` (files). Clean separation, matches rollback architecture.
- Option C — Hybrid: Both inline and standalone endpoints. Most flexible but more complex.

**Decision:** Option B — Separate endpoints. Modeled after `UserController.uploadAvatar` pattern but split into two distinct lifecycle phases.

### Post Update Scope: Full Media Management

**Explored:**
- Option A — Content-only: `PUT` updates text only; media managed only via add endpoint.
- Option B — Full management: `PUT` updates content, standalone endpoints add/delete media individually.

**Decision:** Option B — Full media management. `DeleteMapping("/{postId}/media/{mediaId}")` removes individual media items.

### Media Validation Constraints

**Decision:** Max 10 files per post, max 10MB per file, images (`image/*`) or video (`video/*`) only. Implemented in new `PostMediaValidator` following `ProfileValidator` pattern.

### Feed Endpoint Placement

**Decision:** `GET /api/v1/users/{userId}/posts` lives in `PostController` with full path `@GetMapping("/api/v1/users/{userId}/posts")`. Preserves feature boundaries per developer decision Variant B.

### Author Snapshot

**Decision:** `authorName` = `externalId` from `UserDTO` captured once at post creation time via `UserQueryPort.getProfile(authorId)`. `authorAvatarUrl` excluded entirely from entity, DTO, migration, and API.

### Soft-Delete Implementation

**Decision:** `deleted` boolean field on `Post` with `@PrePersist` default `false`. `PostRepository.findById` overridden with `@Query("SELECT p FROM Post p WHERE p.id = ?1 AND p.deleted = false")`. All callers automatically respect soft-delete.

### Rollback Cleanup

**Decision:** Replicate `UserService.registerRollbackCleanup` in `PostService` for both standalone media upload and full post creation transactions. Files deleted on `STATUS_ROLLED_BACK`.

### MediaStoragePort Extension Strategy

**Decision:** Add `uploadPostMedia(MultipartFile)` to existing `MediaStoragePort`. Extend `LocalMediaStorageAdapter` with `postMediaPath` and `/post-media/` prefix handling in `delete()`. Use `@Qualifier("localMediaStorageAdapter")` on all injection sites to avoid `NoUniqueBeanDefinitionException`.

package lghdnov.msocial.feature.post.entity;

import jakarta.persistence.*;
import lombok.*;

import java.time.Instant;

@Entity
@Table(name = "posts")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class Post {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "author_id", nullable = false)
    private Long authorId;

    @Column(name = "author_name", nullable = false, length = 255)
    private String authorName;

    @Column(name = "content", nullable = false, length = 5000)
    private String content;

    @Column(name = "deleted", nullable = false)
    private Boolean deleted;

    @Column(name = "created_at", nullable = false)
    private Instant createdAt;

    @Version
    private Long version;

    @PrePersist
    public void prePersist() {
        if (createdAt == null) {
            createdAt = Instant.now();
        }
        if (deleted == null) {
            deleted = false;
        }
    }
}

    @Override
    public void delete(String url) {
        if (url == null || url.isBlank()) {
            return;
        }
        try {
            String baseDir;
            if (url.startsWith("/avatars/")) {
                baseDir = avatarPath;
            } else if (url.startsWith("/tracks/")) {
                baseDir = trackPath;
            } else if (url.startsWith("/post-media/")) {
                baseDir = postMediaPath;
            } else {
                throw new ValidationException("INVALID_PATH", "Некорректный префикс пути файла");
            }
            String filename = Paths.get(url).getFileName().toString();
            Path filePath = Paths.get(baseDir, filename).toAbsolutePath().normalize();
            Path basePath = Paths.get(baseDir).toAbsolutePath().normalize();
            if (!filePath.startsWith(basePath)) {
                throw new ValidationException("INVALID_PATH", "Некорректный путь файла");
            }

/**
 * Сервис управления постами.
 *
 * <p>Реализует {@link PostQueryPort}, {@link PostCommandPort}.
 * Оркестрирует работу с JPA-сущностями {@code Post}, {@code PostMedia}
 * и медиа-хранилищем через {@link MediaStoragePort}.
 */
@Service
class PostService implements PostQueryPort, PostCommandPort {

    private final PostRepository postRepository;
    private final PostMediaRepository postMediaRepository;
    private final PostMapper postMapper;
    private final UserQueryPort userQueryPort;
    private final MediaStoragePort mediaStoragePort;
    private final PostMediaValidator postMediaValidator;

    PostService(
        PostRepository postRepository,
        PostMediaRepository postMediaRepository,
        PostMapper postMapper,
        UserQueryPort userQueryPort,
        @Qualifier("localMediaStorageAdapter") MediaStoragePort mediaStoragePort,
        PostMediaValidator postMediaValidator
    ) {
        this.postRepository = postRepository;
        this.postMediaRepository = postMediaRepository;
        this.postMapper = postMapper;
        this.userQueryPort = userQueryPort;
        this.mediaStoragePort = mediaStoragePort;
        this.postMediaValidator = postMediaValidator;

    @Override
    @Transactional(readOnly = true)
    public PostDTO getPost(Long postId) {
        Post post = findPostOrThrow(postId);
        List<PostMedia> media = postMediaRepository.findByPostIdOrderBySortOrderAsc(postId);
        return postMapper.toDto(post, media);
    }

    @Override
    @Transactional(readOnly = true)
    public Page<PostDTO> getFeed(Long authorId, Pageable pageable) {
        Page<Post> posts = postRepository.findAllByAuthorId(authorId, pageable);
        return posts.map(post -> {
            List<PostMedia> media = postMediaRepository.findByPostIdOrderBySortOrderAsc(post.getId());
            return postMapper.toDto(post, media);
        });
    }

    @Override
    @Transactional
    public PostDTO createPost(Long authorId, CreatePostRequest request) {
        UserDTO userDTO = userQueryPort.getProfile(authorId);

        Post post = Post.builder()
            .authorId(authorId)
            .authorName(userDTO.externalId())
            .content(request.content())
            .build();

        Post saved = postRepository.save(post);
        return postMapper.toDto(saved, List.of());
    }

    @Override
    @Transactional
    public PostDTO updatePost(Long userId, Long postId, UpdatePostRequest request) {
        Post post = findPostOrThrow(postId);
        assertAuthorOrThrow(post, userId);

        post.setContent(request.content());
        Post saved = postRepository.save(post);
        List<PostMedia> media = postMediaRepository.findByPostIdOrderBySortOrderAsc(postId);
        return postMapper.toDto(saved, media);
    }

    @Override
    @Transactional
    public void deletePost(Long userId, Long postId) {
        Post post = findPostOrThrow(postId);
        assertAuthorOrThrow(post, userId);

        post.setDeleted(true);
        postRepository.save(post);

    @Override
    @Transactional
    public PostDTO addPostMedia(Long userId, Long postId, List<MultipartFile> files) {
        Post post = findPostOrThrow(postId);
        assertAuthorOrThrow(post, userId);

        List<PostMedia> existingMedia = postMediaRepository.findByPostIdOrderBySortOrderAsc(postId);
        postMediaValidator.validate(files, existingMedia.size());

        int startOrder = existingMedia.size();
        List<String> uploadedUrls = new ArrayList<>();

        for (int i = 0; i < files.size(); i++) {
            MultipartFile file = files.get(i);
            String url = mediaStoragePort.uploadPostMedia(file);
            uploadedUrls.add(url);
            registerRollbackCleanup(url);

            PostMedia media = PostMedia.builder()
                .postId(postId)
                .url(url)
                .sortOrder(startOrder + i)
                .build();
            postMediaRepository.save(media);
        }

        List<PostMedia> allMedia = postMediaRepository.findByPostIdOrderBySortOrderAsc(postId);
        return postMapper.toDto(post, allMedia);
    }

    @Override
    @Transactional
    public void deletePostMedia(Long userId, Long postId, Long mediaId) {
        Post post = findPostOrThrow(postId);
        assertAuthorOrThrow(post, userId);

        PostMedia media = postMediaRepository.findById(mediaId)
            .orElseThrow(() -> new NotFoundException("MEDIA_NOT_FOUND", "Медиафайл не найден"));

        if (!media.getPostId().equals(postId)) {
            throw new lghdnov.msocial.common.exceptions.ValidationException("MEDIA_NOT_IN_POST", "Медиафайл не принадлежит этому посту");
        }

        mediaStoragePort.delete(media.getUrl());
        postMediaRepository.delete(media);
    }

    private Post findPostOrThrow(Long postId) {
        return postRepository.findById(postId)
            .orElseThrow(() -> new NotFoundException("POST_NOT_FOUND", "Пост не найден"));
    }

    private void assertAuthorOrThrow(Post post, Long userId) {
        if (!post.getAuthorId().equals(userId)) {
            throw new AccessDeniedException("NOT_AUTHOR", "Вы не являетесь автором этого поста");
        }
    }

    private void registerRollbackCleanup(String url) {
        if (TransactionSynchronizationManager.isSynchronizationActive()) {
            TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
                @Override
                public void afterCompletion(int status) {
                    if (status == STATUS_ROLLED_BACK) {
                        mediaStoragePort.delete(url);
                    }
                }
            });
        }
    }

package lghdnov.msocial.feature.post.service.validator;

import lghdnov.msocial.common.exceptions.ValidationException;
import org.springframework.stereotype.Component;
import org.springframework.web.multipart.MultipartFile;

import java.util.List;

/**
 * Валидатор медиафайлов поста.
 */
@Component
public class PostMediaValidator {

    private static final int MAX_FILES = 10;
    private static final long MAX_SIZE_BYTES = 10 * 1024 * 1024; // 10MB

    public void validate(List<MultipartFile> files, int existingCount) {
        if (files == null || files.isEmpty()) {
            throw new ValidationException("MEDIA_EMPTY", "Список файлов не может быть пустым");
        }
        if (existingCount + files.size() > MAX_FILES) {
            throw new ValidationException("MEDIA_TOO_MANY", "Максимум " + MAX_FILES + " файлов на пост");
        }
        for (MultipartFile file : files) {
            validateFile(file);
        }
    }

    private void validateFile(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new ValidationException("MEDIA_FILE_EMPTY", "Файл не может быть пустым");
        }
        if (file.getSize() > MAX_SIZE_BYTES) {
            throw new ValidationException("MEDIA_TOO_LARGE", "Максимальный размер файла 10 МБ");
        }
        String contentType = file.getContentType();
        if (contentType == null || !(contentType.startsWith("image/") || contentType.startsWith("video/"))) {
            throw new ValidationException("MEDIA_TYPE_INVALID", "Допустимы только изображения и видео");
        }
    }
}
